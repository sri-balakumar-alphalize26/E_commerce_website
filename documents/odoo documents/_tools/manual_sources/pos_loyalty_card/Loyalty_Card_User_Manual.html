Loyalty Card

Cards, Points & Rewards by Mobile Number
User Manual  |  369ai

What this does

Loyalty Card gives each customer a loyalty card tied to their mobile number. Customers collect points when they buy and can later spend those points as money off. One points rule sets how many points a purchase earns and how much each point is worth, and every change to a card's points is kept in the points history.

This module holds the cards, the rule and the history. It does not sell anything itself: the module that takes the orders gives and takes the points. In 369 Mart that is 369 Mart Loyalty Points. You can also view, print and email a card in the size and colours you choose. Nothing is deleted at once: a deleted card goes to a bin first, and you can bring it back from there.

How the manual is arranged

Part 1 — Setting Up

This is done once by a Loyalty Manager. The module comes with working defaults, so if the defaults below suit your shop, you can go straight to Part 2.

1Where everything lives

The screens are in one of two places, depending on what is installed.

On its own, the module has its own Loyalty app in the main menu, in three sections:

  • Loyalty → Customer Details — your customers who have a mobile number, with a button that makes cards for them.
  • Loyalty → Loyalty Cards — every card, with its points and status.
  • Loyalty → Points Rules — the rule for earning and spending points.
  • Loyalty → Points History — every time points were added or taken, on any card.
  • Loyalty → Loyalty Settings — mobile number rules, the card number format, and the printed card's size, font and colours.
  • Email → Email Settings — the email account cards are sent from, and the welcome message.
  • Images → Card Images and Download Card Images (ZIP) — saved pictures of cards, and a way to download them.

With 369 Mart Loyalty Points installed, the Loyalty app is hidden. The same screens appear under 369 Mart → Loyalty instead, as one list: Loyalty Cards, Customer Details, Points History, Points Rules, Loyalty Settings, Email Settings, Card Images and Download Card Images (ZIP). They open the same screens, so everything in this manual applies in either place.

Good to know: In the Loyalty app, all entries are visible to anyone with the Loyalty User role, but a Loyalty User can only read the rules and settings. Under 369 Mart, Points Rules, Loyalty Settings and Email Settings are shown only to a Loyalty Manager.

2Check Loyalty Settings

Open Loyalty Settings. You see a list of settings records. A ready-made one called Default is already on. You can keep more than one record, for example a festival card design, but only the one with Active switched on is used, everywhere in loyalty. To switch, click the Active switch on another row and confirm with Switch, or open a record and press Set as Active. The one that was on turns off by itself.

Open the active record. At the top:

  • Name — any label, e.g. Diwali Card.
  • Enable Loyalty (master) — the main on/off switch for loyalty. Default on. The selling module (369 Mart Loyalty Points) gives and takes points only while it is on. While it is off, Auto-Email Card is hidden and the Email Settings screen is locked.
  • Auto-Email Card — default off. When on, a card is emailed to the customer (as a picture and a PDF) when it is created already Active, or when a Draft card is first activated. Only customers with an email address get it, and it needs the email account from step 5.

Under Mobile Number (all loyalty):

  • Country — the country of your customers' mobile numbers. Default: your company's country.
  • Dial Code (+) — filled in from the country (for example 91 for India). You cannot type here.
  • Mobile Number Length — how many digits a local mobile number has, without the dial code. Default 10. It is filled in when you pick a country, but you can change it.

Mobile numbers are saved with the dial code in front. If you type 9876543210, the card keeps +919876543210. On the Customer Details form, the dial code is shown as a fixed box and the number box takes only digits, up to the length set here.

Important: At least one settings record must stay on. You cannot switch off the only active one. You get "At least one Loyalty Settings must stay ON…". To change which one is used, turn another one on instead.

3Card number and the printed card's look

On the same Loyalty Settings form, Card Number Format decides how new card numbers are built: prefix + last digits of the mobile + a running counter. A customer whose mobile ends in 90 might get LC90000001. A yellow Card Number Format box at the bottom shows each part and an Example as you type.

  • Card Prefix — the letters at the start. Default LC.
  • Include Mobile Digits — default on. Off leaves the mobile digits out.
  • Mobile Digits Used — how many digits from the end of the mobile number. Default 2.
  • Counter Digits — the length of the running number, filled with zeros. Default 6 (000001).

The card's barcode is the card number without the prefix.

Good to know: A new format applies only to cards made from now on. Cards that already exist keep their number.

The other groups set how a card looks when viewed, printed, emailed or saved as a picture. The Preview beside them shows a sample card that changes as you edit.

  • Card Size (Print) — Card Width (mm) 86 and Card Height (mm) 54 (the size of a bank card). Width must be 40–120 mm and height 25–90 mm; anything outside that is brought back into range. The printed PDF page is exactly the card's size. Font Style chooses the lettering (Arial by default, or Times New Roman, Georgia, Courier New, Verdana, Tahoma, Trebuchet MS, Helvetica, Comic Sans MS).
  • Colors — Background Color (dark blue by default), Text / Number Color, Title Color (the words "LOYALTY CARD"), Customer Name Color, and Company Color, Status Color, Since Color and Points Color for those lines.
  • Font Sizes (mm) — one size for each line: Title, Card Number, Customer Name, Company, Status, Since and Points. Sizes are in millimetres. Each one has a limit based on the card height, so text never runs off the card.
  • Card Image / WhatsApp — Card Company Name is the shop name shown at the top of the card and in the email subject. If you leave it blank, your company name is used. Card Image Retention (months) is explained in Part 3, step 3.
Watch out: Reset to Default asks only about "card size, fonts and colors", but it puts back more than that. It also resets the card number format, the mobile number length, the welcome message, the email server name, port and security, turns Enable Loyalty (master) on and turns Auto-Email Card off. Check those afterwards.

4Set the points rule

Open Points Rules. A Default Rule is already there and on. Open it, or press New for another one:

  • Rule Name — any label.
  • Spend Amount and Points Earned (under Earning Rules) — spend this much, earn that many points. Default: spend 100, earn 10.
  • Min Points to Redeem — the fewest points a customer can spend at one time. Default 100.
  • Points per ₹1 — how many points make ₹1 off. Default 10, so 100 points are ₹10 off.
  • Max Redeem % — the largest share of an order that points may pay for. Default 100 (the whole order).

With the defaults, a ₹500 purchase earns 50 points. Once a customer has 100 points, they can spend them as ₹10 off.

Like the settings, only the Active rule is used. To change rules, click the Active switch on another row and confirm, or press Set as Active on its form. The old rule turns off by itself.

Important: You cannot switch off the last active rule ("At least one Points Rule must stay ON…"). A new rule takes effect from now on. Points already earned stay as they are, but their Points Value (₹) is worked out again with the new Points per ₹1.

5Set up the email account

Open Email Settings. It always opens on the active Loyalty Settings record. If Enable Loyalty (master) is off, you see only a red box, "Please enable "Enable Loyalty (master)" first.", with a switch to turn it on there. Then fill in the account the shop sends cards from:

  • From Name — the sender name customers see, e.g. MyShop Loyalty. If you leave it blank, the card's company name is used.
  • From Email — the sending address. For Gmail it must be the same as the Username.
  • SMTP Server, Port, Security — the mail server's details. These are ready for Gmail: smtp.gmail.com, 587, TLS (recommended). The other choices for Security are None and SSL.
  • Username — usually the same as From Email.
  • Password / App Password — for Gmail, the App Password (see below). It shows as dots.
  • Email Ready — switches on by itself once the account is saved.

Press Save Email Settings. You need at least From Email and SMTP Server; otherwise you see "Please fill at least the From Email and SMTP Server." Then press Send Test Email. A test message goes to the From Email address. If it arrives, sending cards will work.

Getting a Gmail App Password. Gmail does not accept your normal password here. A yellow box at the bottom of the screen has links for these steps. Do this once:

  • Turn on 2-Step Verification for the Google account. App passwords only become available after that.
  • Create an App Password. Type any name for it, and Google gives you a 16-character code.
  • Put your full Gmail address in Username. Paste the code into Password / App Password; the spaces are optional.
Tip: If the test fails, the message says why, for example a wrong password. Check the SMTP Server, Username and App Password, then press Send Test Email again.

6Write the welcome message

Lower on the Email Settings screen, Welcome message for new customers (Email) is the text at the top of every card email, above the card picture. Choose a Welcome Message Mode:

ModeHow you write it
Simple (fill-in-the-blanks) — defaultFill in a Header, an Intro line, an Instructions line and a Footer. Then switch on or off: Show greeting (Dear name), Show intro line, Show card number, Show mobile, Show points, Show instructions line.
Advanced (full template)Write the whole message yourself in one box, using the fill-in words below.

Fill-in words are replaced with each customer's own details when the email is sent. They work in Advanced mode and in the Simple text lines. Type them exactly, with the curly brackets:

Type thisThe customer sees
{name}Their name, e.g. Priya.
{card_number}Their card number, e.g. LC90000001.
{phone}Their mobile number, with the dial code.
{points}Their points at the moment the email is sent.

Put a word between stars to make it bold: *Welcome* shows as Welcome. The Live Preview underneath shows the message with sample details as you edit. Reset Message to Default puts back the original text.

Part 2 — Everyday Use

This is what staff use from day to day. A Loyalty User can do everything here.

1Find a card

Open Loyalty Cards. The list shows each card's number, customer name, mobile number, Total Points, Points Value (₹), Registration Date and Status. It opens with the Active filter on. Remove that filter to see Draft and Suspended cards too, or use the Draft and Suspended filters. Type in the search box and pick Card/Name/Phone to search all three at once. You can also group the list by Status or by Registration Date (month).

2Make a card by hand

In Loyalty Cards, press New and fill in:

  • Customer Name and Mobile Number — both are needed.
  • Email — needed only if you want to email the card.

Save. The card number appears (until then it says New), along with the barcode and the registration date. The card is linked to the customer with that mobile number. If there is no such customer yet, one is created for you; it shows in the Partner field. A new card starts as Draft. Press Activate to make it usable.

Important: One mobile number can have only one card (in each company). A second card with the same number is refused with "Phone number must be unique per company! Card … already has this number." Cards in the bin do not count.

3Make cards from Customer Details

Open Customer Details. It lists people (not companies) who have a mobile number and are not in the bin: Customer ID, Customer Name, Mobile Number, Email and Registered On. The filters are With Mobile (on by default), With Email and Not Deleted, and you can group by City or Registration Date. You can also add a customer here with New.

  • Generate Loyalty Cards (at the top of the list) — makes cards for all customers at once. A box asks "Generate loyalty cards for all customers who don't have one yet?". Press Generate.
  • Generate Loyalty Card (inside one customer) — does the same for that customer only.

For each customer: with no card, a new Active card is made. With a Draft or Suspended card, that card is made Active. With an Active card already, or with no mobile number, the customer is skipped. A message then gives the counts, e.g. "3 created, 1 activated, 2 skipped (already active or no mobile number)." The customer's own Loyalty Cards tab lists their cards.

Watch out: Generating also turns Suspended cards back on. If you suspended a card on purpose, generating for that customer (or for everyone) makes it Active again. If Auto-Email Card is on, each newly made card is also emailed to customers who have an email address.

4Inside a card

Click a card to open it. The left side shows the Customer Information (name, mobile, email). The right side shows the Card Details: Total Points, Points Value (₹), Barcode, Registration Date and Partner (the customer the card belongs to). The Points History tab lists every time points were added or taken on this card, newest first. You can read it but not change it. The buttons at the top depend on the status:

ButtonShown whenWhat it does
ActivateDraftMakes the card usable. If Auto-Email Card is on, the card is emailed now.
SuspendActivePuts the card on hold. A suspended card cannot be used to spend points.
ReactivateSuspendedMakes the card Active again.
View CardActive or SuspendedOpens the card on screen in a new browser tab, with a Print Card link.
Print CardActive or SuspendedMakes a PDF exactly the size of the card, ready to print.

Watch out: Add 500 Test Points adds real points. At the default rule, they are worth ₹50 the customer can spend, and there is no undo button. Use it only on test cards, never on a real customer's card.

5View, print and email a card

The card shows the shop name, the words LOYALTY CARD, the card number, the status, the customer's name, SINCE (the month and year it was registered), POINTS and a barcode. Its size, font and colours come from the active Loyalty Settings.

  • View Card — to show the card on screen to a customer, or to print from the browser.
  • Print Card — one card as a card-sized PDF. To print several cards, tick them in the Loyalty Cards list and choose Print → Loyalty Card.
  • Email Card — sends an email with the subject "Your [shop] Loyalty Card - [card number]". The email contains the welcome message and a picture of the card, with the card attached as a picture and as a PDF. A green message confirms "The loyalty card was emailed to …".
Tip: "No Email" means the card has no email address; add one on the card and try again. "Not Sent" means the email account is not working. Open Email Settings and press Send Test Email to find out why.

6The Points History screen

Open Points History to see every points entry on every card. It opens grouped by day, then by card. Each row shows the Date, Card, Type (as a coloured label), Points, Description and Order Amount. The search box finds a card number, customer name, phone or description. The filters are Earned, Redeemed, Returned and Refunded (points back), and you can group by Card, Type or Date.

A card's Total Points is worked out from its history: Earned minus Redeemed minus Returned, plus Refunded. The four types are explained in the reference table near the end.

7How points are earned and spent

Points are added and spent by the module that takes the orders (369 Mart Loyalty Points). That module uses the active Points Rule. Earning goes in step with the amount spent: with the default rule, every ₹100 earns 10 points. Spending follows these rules, and a customer who breaks one is refused:

  • The card must be Active — a Draft, Suspended or deleted card cannot spend points.
  • At least the minimum — the customer must spend at least Min Points to Redeem (default 100).
  • Enough points — no more than the card's Total Points.
  • Once a day — one spend per calendar day. The limit resets at midnight in your time zone. A second try gets "Redemption allowed only once per day.", with the time it was last used and when it can be used again.

The money off is the points divided by Points per ₹1. For example, 250 points at 10 per ₹1 is ₹25 off.

8Card images

Card Images is a gallery of saved pictures of cards. Each picture records the card number, customer, phone, the points at that moment and the Event (Card Created or Order). It opens grouped by date and card number. Switch to the tile view to see the pictures large, and click one to zoom. You cannot add pictures here by hand.

To take pictures away as files, open Download Card Images (ZIP) and choose under Download:

DownloadWhat you pick
All images (default)Nothing more. Every saved picture.
By card numberOne Loyalty Card. All its pictures.
By date rangeFrom and To dates (both needed). The pictures saved on those days.

Press Download ZIP. You get one zip file, with each picture named by card number and date. If nothing matches, you see "No card images found for this selection."

Good to know: This module does not save pictures by itself. The gallery fills only when a connected module saves a card picture. An empty gallery just means none has been saved yet.
Part 3 — Keeping It Secure & In Order

1Deleting safely

In Loyalty Cards or Customer Details, tick the rows and press Delete Selected. Inside one customer, press Delete Customer. Nothing is deleted yet. A Confirm Delete window first shows what will happen:

  • Deleting cards — it lists the cards (number, customer, mobile, points, value) and any customers who share the same mobile number. Those customers are deleted too.
  • Deleting customers — it lists the customers and any loyalty cards that share the same mobile number. Those cards are deleted too. A red line gives the Total Points to be lost and what they are worth.

Press Confirm Delete to go ahead, or Cancel. Confirmed items go to the bin: deleted cards are also set to Suspended, and both leave the normal lists.

Important: Read the second table before confirming. Deleting one card can also move the matching customer to the bin, and the other way round. This is so a mobile number never stays half in use.

2The bin: restore or delete for good

At the top of Loyalty Cards, press Deleted Loyalty Cards. At the top of Customer Details, press Deleted Customers. Each opens a window listing what was deleted and when (Deleted On). Tick rows, or open one, and choose:

  • Restore Selected / Restore Card / Restore Customer — brings it back. A restored card comes back as Active, with its points history.
  • Delete Permanently — removes it for good, after a warning. A card goes with all its points history. If that leaves the customer with no card, the customer moves to Deleted Customers. A customer deleted for good takes their loyalty cards with them.
Watch out: Delete Permanently cannot be undone, and the points are lost. Also, restoring a card does not restore the customer that was deleted with it, so restore that customer from Deleted Customers as well. A card cannot be restored while another card already uses its mobile number.

3Old card images are cleared

Once a day, the job Loyalty: Delete Old Card Images removes saved card pictures older than Card Image Retention (months) in the active Loyalty Settings. The default is 6 months; one month counts as 30 days. Set it to 0 to keep pictures forever. Download any pictures you want to keep (Part 2, step 8) before they reach that age. Only pictures are removed; cards and points are never touched.

5Privacy

A card holds a customer's name, mobile number and email address, and only staff with a loyalty role can see them. The email password shows as dots. Use a Gmail App Password, not the real password: it can be cancelled in Google at any time without changing the main one. If a customer asks to be removed, delete them, then use Delete Permanently in the bin.

Quick tips

  • One mobile number, one card. Cards in the bin don't count.
  • Only the Active points rule and the Active Loyalty Settings are used. Switch by turning another one on.
  • A new card number format affects new cards only.
  • Generate Loyalty Cards also reactivates Suspended cards, so think before running it for everyone.
  • Use Add 500 Test Points on test cards only. Those points can really be spent.
  • Press Send Test Email after any change to the email account.
  • Read both tables on the Confirm Delete window: a matching customer or card goes too.
  • Download card pictures you need before the retention period (6 months by default) clears them.
