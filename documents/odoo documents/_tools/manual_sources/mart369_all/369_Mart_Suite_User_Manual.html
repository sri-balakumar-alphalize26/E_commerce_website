369 Mart Suite

Every 369 Mart Module in One Install
User Manual  |  369ai

What this does

369 Mart Suite is a shortcut. It has no screens and no settings of its own. Installing it installs the base (369 Mart) and every standard part of the shop in the right order, so you install one thing instead of a dozen.

Each part can still be installed on its own. If you only want some of the shop, skip the Suite: install 369 Mart and then pick the parts you want from the Apps list.

Before you start: Installing needs an administrator (Administrator (Settings)). Nothing is asked during the install; everything you set up afterwards is described in each module's own manual.

Add them yourself if you need them: 369 Mart: New Orders Board (the shop counter's orders screen), 369 Mart: WhatsApp Bridge (one shop across the website and WhatsApp selling; also what sends sign-in codes on WhatsApp) and 369 Mart Sample Catalogue - Computer Parts (sample products for trying the screens).

When to use it

  • New shop, full setup — install the Suite.
  • Only some parts — install 369 Mart and the parts you want, one by one.
  • Adding a missing part later — install just that part; the Suite is not needed.

How to remove it

Uninstalling the Suite removes only the Suite itself. Every module it brought in stays installed and keeps working, with all your data. To remove a part, uninstall that part. Uninstalling 369 Mart (the base) offers to remove the whole suite, because every part depends on it.

Watch out: Removing a part can remove the screens of other parts that need it. Read the list of modules the uninstall offers before you confirm.

If something goes wrong

What you seeWhat to do
The Suite doesn't appear in AppsSearch Apps for "369 Mart Suite". If it is still missing, the 369 Mart modules are not on the server yet: ask whoever looks after your system to add them and update the apps list.
A screen I expected is missingIt may belong to a module the Suite does not install (see the Good to know box above). Install that module.
Sign-in codes on WhatsApp don't arriveThe WhatsApp Bridge is not part of the Suite. Install it to send codes.
