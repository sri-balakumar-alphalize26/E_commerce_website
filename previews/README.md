# Previews

Standalone single-file pages — double-click to open in any browser, no install needed.
They run the same components as the app with sample data and inline sample images.

- `home.html` — home, Quick / Express switch, location picker, search, product galleries, cart bar
- `cart.html` — cart page
- `account.html` — account page
- `sign-in.html` — sign-in page

Fonts load from Google Fonts when online (system font fallback offline).
